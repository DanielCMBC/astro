# Archived review snapshots

Point-in-time external reviews of a milestone, kept for history.

They are **not** current documentation. Every durable decision a review
produced has been folded into the real docs — `docs/architecture.md`,
`docs/physics.md`, `docs/orbital-semantics.md`, `docs/explorer-b.md`,
`docs/roadmap-status.md` — and those win wherever the two disagree. A
review describes the code as it stood when the review was written, so parts
of it are deliberately out of date.

Generated review files do not belong at the repository root.
